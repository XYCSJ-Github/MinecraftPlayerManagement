# Minecraft Player Management（mpm 玩家档案管理）

一个用于管理 **Minecraft Java 版** 存档与玩家数据的桌面小工具，支持**单人客户端（`.minecraft`）**与**服务端**两种目录，帮助你查看并清理玩家数据。

## 它能做什么

- 打开一个 Minecraft 目录（客户端 `.minecraft` 或服务端根目录），自动识别类型并列出其中的**存档**与**玩家**。
- **存档视图**：进入某个存档后，查看每位玩家在该存档里的数据情况：
  - 进度（Advancements）
  - 玩家数据（playerdata）
  - 旧版玩家数据
  - 装饰盔甲数据
  - 统计（Stats）
- **玩家视图**：查看单个玩家在**所有存档**中的足迹，支持按昵称或 UUID 搜索。
- 支持几种删除操作：
  - 删除某个玩家在**某个存档**中的数据；
  - 清除某个存档的**全部玩家数据**；
  - 清理 `usercache / usernamecache` 中的玩家缓存记录；
  - 从**所有存档与缓存**中彻底删除某个玩家。

> 所有删除都只是把文件移入**回收站**，不会直接删除，随时可以恢复。

## 使用说明

### 1. 启动程序

直接运行 `mpm_GUI.exe`；或使用 All-in-One 单文件版 `MinecraftPlayerManagement.exe`（无需安装，自带引擎与界面）。

### 2. 打开 Minecraft 目录

1. 打开程序后，在**概览**页点击「选择并打开文件夹」。
2. 选择：
   - 单机客户端目录：`....\.minecraft`（里面应包含 `saves` 文件夹），或
   - 服务端目录：服务端解压后的根目录（存档文件夹直接位于其中）。
3. 程序会自动识别模式并显示存档数、玩家数。

> 提示：单机玩家数据在存档里通常叫「世界/存档（World）」，一个客户端可含多个存档。

### 3. 管理存档

在**存档**页：

- 左侧为存档列表，点击「查看」查看某个存档中的玩家数据。
- 右侧表格的每一列表示一类数据，✓ 表示存在、— 表示没有。
- 可「删除」某位玩家在该存档中的数据，或点击右上「清除本存档全部玩家数据」。

### 4. 管理玩家

在**玩家**页：

- 列表来自 `usercache` / `usernamecache`，可搜索。
- 点击「查看」查看该玩家在所有存档中的足迹。
- 「清缓存」仅移除该玩家的缓存记录。
- 红色垃圾桶图标表示**从所有存档与缓存中彻底删除**，操作前会二次确认。

### 5. 引擎与日志

在**设置**页：

- 显示并配置 `mpm.exe` 路径；mpm 是程序内置的辅助程序，正常情况下无需手动操作，若提示未连接可点击「启动mpm」或「重启mpm」。
- 「运行日志」可查看最近的引擎输出，便于排查问题。

## 注意事项

- 目前仅支持 **Windows x64**，仅支持 **Minecraft Java 版**。
- 删除前请尽量**先备份**重要的存档（尤其是服务端数据）。
- 删除操作会同时涉及存档文件夹内的文件与 `usercache.json` / `usernamecache.json` 缓存。
- 若提示「mpm未就绪 / 未连接」，请到**设置**页确认 mpm.exe 路径是否正确并点击「启动mpm」。
- 若要打开的不是 `saves` 目录本身，而是含 `saves` 的 `.minecraft` 上级目录，请选择 `.minecraft` 这一级。
